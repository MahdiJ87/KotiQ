# KotiQ

KotiQ is a web application that enables apartment residents to reserve shared building facilities and access building announcements through a centralized digital platform.

## Planned Technologies

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Next.js API Routes
- Node.js

### Database
- PostgreSQL
- Prisma ORM

## Features
- User authentication
- Facility reservations
- Reservation conflict prevention
- Announcement board
- Admin management
